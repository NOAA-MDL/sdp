### CONTRIBUTING TO SDP
External contributions, bug reports, and feature requests can be submitted via
GitHub Issues or Pull Requests. Please ensure any code changes are tested
against the latest `dev` branch before submitting.

### INTERNAL NWS MAINTAINERS
For core team members responsible for cutting official releases, managing the
`sloshdsp.kit` builds, and maintaining the GitHub Actions CI/CD pipeline, please
refer to the internal Standard Operating Procedures.

**SDP Release Handbook & Workflow:**
* Please navigate to the SDP VLab Wiki Home Page:
  https://vlab.noaa.gov/gitlab-community/NWS/Operations/STI/MDL/storm-surge/sdp/sdp/-/wikis/home
* Download the `sdpWorkFlow.md` file for the complete step-by-step instructions.
